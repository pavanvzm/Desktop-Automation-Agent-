## What is an ADR?

An Architecture Decision Record is a document that captures an important architectural decision made along with its context and consequences.

### Format

- **Title**: Descriptive title
- **Status**: Proposed, Accepted, Deprecated, Superseded
- **Context**: What is the issue we're seeing that is influencing this decision?
- **Decision**: What is the change we're proposing and/or doing?
- **Consequences**: What becomes easier or more difficult to do because of this change?

## Creating a New ADR

1. Copy the template below
2. Name the file `ADR-NNN-Title.md`
3. Fill in the sections
4. Set status to "Proposed"
5. Submit for review
